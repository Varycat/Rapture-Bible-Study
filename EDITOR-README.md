# Bible Study Library v13 — Owner Study Editor

New owner-only capabilities:
- Edit study title, subtitle and description
- Edit each topic
- Add/delete/reorder topics
- Edit Pre-Tribulation, SDA and Bible-First sections
- Add personal notes
- Add images by URL or device upload
- Device images are compressed before being stored
- Change per-topic font size, text color and background
- Add custom sections
- Save changes directly to Firestore
- Readers never see editor controls
- Reader progressive access remains controlled in Settings

Private Rapture seed:
Use `Bible-Study-Library-v13-OWNER-SEED.zip`.
Do not upload the private seed to GitHub.

Official Adventist references are stored in the study metadata.
